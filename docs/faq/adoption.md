# Adoption FAQ

## Should we consume, adapt or fork?

Consume when the shared contract and operating ownership fit. Implement adapters when
existing institutional services remain authoritative. Fork only when independent ownership,
naming or release cadence is required.

## Can we retain an existing search platform?

Yes. Implement the relevant ports, bind the profile explicitly, preserve tenant/ACL and
citation semantics, and run contract, eval, demo and portability evidence.

## Is the rename utility destructive by default?

No. It previews, validates output names and refuses a package-directory collision before
writing.
